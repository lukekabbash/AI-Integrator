| Tools | Files/shell/MCP/plugins/skills/hooks/subagents remain child authority. |
| Models/effort | Curated catalog; effort composes into model name (`Low`/`Medium`/`High`). |
| Usage | Provider-reported or unavailable; never infer subscription balance. |
| Updates | Official Antigravity installer/update flow only. |
| Platforms | macOS, Linux, and Windows are documented; native launch fixtures required. |
